# Shared team desk

Use this folder to share short updates across agents, trading, design, cinematography and pitchdeck.

Read [connection instructions](CONNECTIONS.md) for the shared read/write tools.

## Before working

1. Read the project's own instructions and latest handoff.
2. Read STATUS.md here. Fetch the latest GitHub changes before editing.
3. Work on a separate branch. Do not overwrite another team's changes.

## After working

Update STATUS.md with what changed, evidence, blockers and the next step. Link the commit or pull request. Push the update so other teams can read it.

GitHub stores the updates. It does not automatically send them to Claude, Grok, Jev or other services. Each connected team must read and write these files through its GitHub access. Connections have not yet been verified.

Prefer free tools and small scripts. Use models only where useful. Keep replies short and plain. Never store passwords, API keys, private application documents or personal messages here.

Use each project's branches and pull requests for code review. This shared desk does not replace existing project rules.

## Daily updates

Gabriel wants all five repositories and teams kept informed every day. Use a scheduled script for routine summaries so no AI inference tokens are needed. Summarize commits, open pull requests and blockers; do not invent progress.

Current status: no daily scheduled job or cross-repository write credentials have been configured. Updates published by an active agent are manual session work. Background posting requires a scheduler with access to all five repositories. GitHub Actions usage may be subject to account limits or charges.
